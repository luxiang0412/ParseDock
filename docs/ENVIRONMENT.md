## 5. Network and download authorisation

The PoC required outbound HTTPS for: PyPI packages, GitHub release binaries,
Hugging Face / GitHub model weights (docling-rs `models-v1`, MinerU flash
models), and Docker Hub images. No test document was uploaded to any third
party. MinerU's telemetry was explicitly disabled (`mineru telemetry disable`)
and the remote `mineru.net` tier was never used.

The corpus in `test_data/` (4.4 GB of real corporate audit material) was **not**
used for any benchmark, was never copied off the machine, and no content from it
appears in logs or reports. The benchmark corpus is synthetic
(`benchmark/fixtures`, generated by `benchmark/scripts/gen_fixtures.py`) so it can
be shared and reproduced.

## 6. Reproducing the environment

```bash
# 1. Python engine sandboxes (isolated venvs)
python3 -m venv runtime/engines/venv-doclingd && runtime/engines/venv-docling/bin/pip install docling==2.145.0 docling-serve==1.38.2
python3 -m venv runtime/engines/venv-mineru  && runtime/engines/venv-mineru/bin/pip install mineru==4.1.2
python3 -m venv runtime/engines/venv-fixtures && runtime/engines/venv-fixtures/bin/pip install reportlab python-docx openpyxl pillow pypdf

# 2. Prebuilt Rust CLIs
curl -L -o /tmp/x.tgz https://github.com/xberg-io/xberg/releases/download/v1.3.10/xberg-cli-x86_64-unknown-linux-gnu.tar.gz
mkdir -p runtime/engines/xberg-cli && tar xzf /tmp/x.tgz -C runtime/engines/xberg-cli --strip-components=1
curl -L -o /tmp/d.tgz https://github.com/docling-project/docling.rs/releases/download/v2.53.3/docling-rs-v2.53.3-x86_64-unknown-linux-gnu.tar.gz
mkdir -p runtime/engines/docling-rs && tar xzf /tmp/d.tgz -C runtime/engines/docling-rs
(cd runtime/engines/docling-rs && curl -fsSL https://raw.githubusercontent.com/docling-project/docling.rs/master/scripts/install/download_dependencies.sh | bash -s -- --no-asr --no-chunk)

# 3. Tika and docling-serve
docker run --rm -p 15002:9998 apache/tika:latest-full
runtime/engines/venv-docling/bin/docling-serve run --host 127.0.0.1 --port 15001

# 4. MinerU (local daemon, telemetry off)
runtime/engines/venv-mineru/bin/mineru telemetry disable
runtime/engines/venv-mineru/bin/mineru server start
```
