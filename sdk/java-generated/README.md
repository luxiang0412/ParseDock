ParseDock converts documents (PDF, DOCX, XLSX, PPTX, CSV/TSV, TXT/Markdown,
PNG/JPEG/WebP) into a structured Document IR plus derived Markdown/Text.

Lifecycle in one paragraph: `POST /v1/jobs` uploads and queues a job and
returns `202`; a worker parses it; the result is downloadable while
`retention_status=active`. `POST /v1/jobs/{id}/ack` records the client's
intent to release the result and returns `202` (`release_pending`); deletion
is asynchronous. Without an ACK the result expires at `result_expires_at`.
After release/expiry, downloads return `410 Gone` for a short tombstone
window and `404` afterwards.

**Never auto-ACK.** A `200` on a download means the bytes left the server,
not that the client consumed them.

Ownership: every job belongs to the owner derived from the bearer token.
A job that belongs to somebody else is indistinguishable from a missing job
(`404`) to avoid existence leaks.
